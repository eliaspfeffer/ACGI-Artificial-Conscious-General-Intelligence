# My Künstliches Bewusstsein (KB) Project

This is a demo project attempting to implement some core ideas of a "künstliches Bewusstsein" (KB) or general artificial intelligence (AGI), including:

1. A **Knowledge Graph** (neurons + links)
2. An **Endlos (endless) Impulse Engine** that continuously selects the next thought
3. A **NeedsSystem** representing a simplified Bedürfnispyramide (needs hierarchy)
4. A **Semantics Checker** for rudimentary sanity checks

---

## Quick Start

1. **Install Requirements** (optional if you have a recent Python version):

   ```bash
   pip install -r requirements.txt
   ```

2. **Run Simulation:**

   ```bash
   python simulator.py
   ```

   Or:

   ```bash
   python main.py
   ```

   You can adjust the `--steps` and `--delay` flags in `main.py` for customization:

   ```bash
   python main.py --steps 100 --delay 0.5

   ```
