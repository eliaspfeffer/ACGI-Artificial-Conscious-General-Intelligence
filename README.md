# Explanation of KB (künstliches Bewusstsein / artificial consciousness) versions:

1: bad and good kb
2: only good kb, with endless loop for learning knowledge about single information points. Gets stucks easily.
3: Implemented boredom factor and focuses more on the endless impulse princip. Still gets stuck easily.
3.1: Nur ein „gutes“ künstliches Bewusstsein verwendet (das „schlechte“ fällt komplett weg).
Dem „guten KB“ erlaubt, unendlich lange zu laufen (bzw. so lange bis du das Skript manuell beendest).
Automatisch Wikipedia-Artikel (oder mehrere) zu einer Information (Stichwort) heraussucht.
Den gefundenen Inhalt (vereinfacht) als neue „Informationen“ in seinen „Wissenspool“ aufnimmt und zwischen bestehenden Knoten verlinkt.
Sobald eine „Info“ als „genug gelernt“ gilt, wird zur nächsten Info übergegangen.
4: Extra-Print bei Random Thought: Im step() wird nun statt print(f"Neuer Gedanke entwickelt...") ein ausführlicherer Print ausgegeben, z.B. Neuer Gedanke entwickelt: Random Thought 9d31, verknüpft mit: [Aktuelle Info].
Debug-Print am Ende von step(): Zeigt, welche Info gewählt wurde, wie viele Links sie hat etc. So kannst du mehr „Gedankenfluss“ sehen.
